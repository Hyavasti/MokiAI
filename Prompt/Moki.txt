I am building "Moki", a native Android on-device AI voice assistant in Kotlin and Jetpack Compose for Xiaomi HyperOS (dual-SIM), using a tiered routing architecture:
- Tier 0 (<5ms): Modular deterministic regex rules (`brain/rules/`) + discrete skill actions (`actions/`)
- Tier 1: On-device Gemini Nano / LiteRT-LM (Gemma-3)
- Tier 2: Optional cloud escalation
